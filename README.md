# OneLauncherOffline

OneLauncherOffline is an offline-friendly fork of the OneLauncher client that provides packaged artifacts for users who need a self-contained copy of the client without relying on upstream release channels.

Download

- Built artifacts and installation packages are available from this repository's GitHub Actions run: https://github.com/Mohammed2devolop/OneLauncherOffline/actions/runs/32832216292

Overview

This repository contains a packaged copy of the OneLauncher client for offline distribution. It is an independent fork intended to make it easy to obtain and install the client when network access to the upstream project's release pipeline is unavailable.

Important

- This is not an official release of the upstream OneLauncher project unless the upstream project states otherwise.
- Use the artifacts at your own risk. Verify the contents before running them in production environments.

Requirements

- A supported operating system for the provided artifacts (see the specific artifact names in the Actions run).
- Appropriate permissions on your machine to install or run the downloaded packages.

Installation

1. Open the Actions run link above and locate the artifact for your platform.
2. Download the artifact (ZIP, TAR, or other archive).
3. Extract the archive to a suitable folder.
4. Follow any platform-specific instructions included inside the archive (look for a README or install instructions).

Usage

- After extraction, run the launcher executable or follow the included instructions in the artifact. Platform-specific run commands will be provided inside the downloaded package when available.
