# OneLauncherOffline

OneLauncherOffline is an offline-account friendly fork of the OneLauncher client that doesnt require microsoft account like source Onelauncher does to use the app .

Download

- Built artifacts and installation packages are available from this repository's GitHub Actions run: https://github.com/Mohammed2devolop/OneLauncherOffline/actions/runs/32832216292

Overview

This repository contains a packaged copy of the OneLauncher client for offline distribution. It is an independent fork intended to make it easy to obtain and install.

Requirements

- A supported operating system for the provided artifacts (see the specific artifact names in the Actions run).

Installation

1. Open the Actions run link above and locate the artifact for your platform.
2. Download the artifact (ZIP).
3. Extract the archive to a suitable folder.
4.Open the file and install normally

If you have questions or discover problems with the artifacts in this repository, please open an issue: https://github.com/Mohammed2devolop/OneLauncherOffline/issues
